Aufgabe 2.2
Data Story Serviceleitung
1. Der Code für die Generierung von Boxplots für die Bewertung für die Jahre 2016 - 2018 wurde von der KI erzeugt. Durch das Zeichnen wurde festgestellt, dass es die richtigen Boxplots zeichnet.
2. Für den durchschnittliche Bewertung pro Monat wurde der Code von der KI verwendet. Nach Überprüfung wurde festgestelt, dass es das macht was es machen soll.
3. Für die Anzahl schlechter Bewertungen pro Tag wurde die KI gefragt, wie es berechnet wird. Der dazugehörige Code ist auf Korrektheit überprüft worden.
4. Es wurde für die Bestimmung des Zusammenhangs von Gesamtkosten und Bewertung die Bestimmung des Spearman-Korrelationskoeffizienten von der KI vorgeschlagen. Da Bewertung ein ordinalskalierter Wert ist und Gesamtkosten metrisch sind, ist dies möglich und sinnvoll.
